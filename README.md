# Pedro Coelho — PAPACREATOR

Escritor investigador e criador digital. Construo sistemas locais para criar, investigar, organizar conhecimento e automatizar trabalho repetitivo — com privacidade, memória própria e controlo humano.

## O que construo

- Sistemas **local-first** de criação e conhecimento
- Automação prática para escrita, investigação e publicação
- Fluxos com Markdown, SQLite, Python e ferramentas locais
- IA como assistente — nunca como autoridade final
- Conteúdo: livros, crónicas, análise, vídeo, música e projetos multimédia

## Nexus / Cérebro Independente

O meu projeto principal é o **Nexus**: um estúdio pessoal local-first onde escrevo em linguagem natural e o sistema organiza processos, memória, fontes, ferramentas e resultados.

A ideia é simples:

- menos dispersão;
- mais controlo;
- memória e proveniência preservadas;
- trabalho repetido transformado em processos reutilizáveis;
- decisão humana antes de algo se tornar definitivo.

## Princípios

- A pessoa mantém a autoridade final.
- IA não é autoridade.
- Memória não é autoridade.
- Privacidade e controlo local são prioridade.
- Ferramentas devem ser substituíveis.
- Nada entra no definitivo sem revisão humana.
